The scores, explained

Scores are pre-computed by Open Food Facts contributors worldwide - NutriLens just brings them to your storefront. Data licensed under ODbL. NutriLens is not affiliated with any grocery stores.

Nutri-Score

Overall nutritional quality, from a (best) to e.

Green-Score / Eco-Score

Environmental impact of the product, from a+ to f.

NOVA group

Processing level, from 1 (unprocessed) to 4 (ultra-processed).

Nutrient levels

Fat, saturated fat, sugar and sodium at unknown / low / moderate / high.

Try it today

Grab a pre-built zip from GitHub Releases and load it into your browser in under a minute.

⬇ Download Chrome build (.zip) ⬇ Download Firefox build (.zip)
1

Download

Grab the latest release zip for your browser from the Releases page.

2

Unzip

Extract the archive anywhere you like - keep the folder around.

3

Load it

Follow the browser steps below, then open a supported store.

🟡 Chrome / Edge / Brave

  1. Open chrome://extensions
  2. Enable Developer mode (top-right toggle)
  3. Click Load unpacked
  4. Select the unzipped chrome-mv3 folder

🦊 Firefox

  1. Open about:debugging#/runtime/this-firefox
  2. Click Load Temporary Add-on…
  3. Pick manifest.json inside the unzipped firefox-mv2 folder

Prefer building from source? See the README instructions.
